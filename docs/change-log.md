*** User wants the Price History and Trade History interactive chart modals in the portfolio backtest HTML report to render correctly — clicking "Price History" opens the modal but shows an empty chart (only the TradingView watermark visible, no candlestick data).
*** Opus 4.6 Decision: Pinned the LightweightCharts CDN dependency from an unversioned URL (`unpkg.com/lightweight-charts/dist/...`) to a specific version (`unpkg.com/lightweight-charts@4.2.0/dist/...`). The root cause was that the unversioned CDN URL had silently upgraded to LightweightCharts v5.2.0, which introduced breaking API changes — notably, `chart.addCandlestickSeries()` was removed in favor of `chart.addSeries(SeriesType.Candlestick, ...)`. The chart canvas was being created (hence the visible TradingView watermark), but the candlestick series creation call was failing silently under v5, resulting in an empty chart. Pinning to v4.2.0 was chosen over migrating to the v5 API because it is a single-line, zero-risk fix that restores full compatibility with all existing chart code (`addCandlestickSeries`, `CrosshairMode`, `LineStyle`, `createPriceLine`), whereas a v5 migration would require refactoring multiple API calls across the template with no functional benefit. File changed: `src/utils/html_exporter.py` (line 150).
